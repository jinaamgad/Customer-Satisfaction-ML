# Customer Satisfaction ML System

A machine learning project that predicts customer satisfaction using data analysis and a Decision Tree model.

## Features
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Machine Learning model (Decision Tree)  
- Model evaluation (accuracy, confusion matrix)  
- Interactive Gradio interface for real-time predictions  

## Tech Stack
- Python  
- Pandas  
- Scikit-learn  
- Matplotlib  
- Gradio  

## How to Run
1. Install required libraries  
2. Run the Python script or notebook  
3. Launch the Gradio interface
